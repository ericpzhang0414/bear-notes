# Reference 笔记模板

## 标准模板（完整收录）

```
# 内容标题
#reference/子标签

> **来源：** [URL 或 文件名]
> **收录：** YYYY-MM-DD

## 关键内容

（用自己的话总结核心观点。不收录全文——这是整理而非搬运。
必要时引用原文摘要，用 `>` 标记）

> 原文关键段落

## 我的思考

（与原文区分。用户在做收录时如果有想法/启发/疑问，写在这里。）

## 关联笔记

- [[相关笔记标题]]：关联说明
- [[另一篇笔记]]：关联说明
```

## 简洁模板（快速收录）

```
# 内容标题
#reference/子标签

> **来源：** [URL]
> **收录：** YYYY-MM-DD

## 关键内容

核心要点总结。

## 关联笔记

- [[相关笔记]]
```

## 字段说明

| # | 字段 | 必需 | 说明 |
|---|------|------|------|
| 1 | 标题 | ✅ | 内容标题，无需日期前缀 |
| 2 | 类型 | ✅ | 行2标签，即内容类型 |
| 3 | 来源 | ✅ | URL / 文件名 / 「手动粘贴」/ 「个人想法」 |
| 4 | 收录时间 | ✅ | `> **收录：** YYYY-MM-DD` |
| 5 | 关键内容 | ✅ | 自己总结，非全文搬运。必要时 `>` 引用原文 |
| 6 | 我的思考 | 条件 | 用户有评论→提取；纯指令→省略 |
| 7 | 关联笔记 | 条件 | ≥1条→保留；无→省略 |

## 区段规则

- `## 关键内容` — 必需。总结核心信息，保持简洁。
- `## 我的思考` — 条件。用户评论用 `> 💭` 前缀区分。
- `## 关联笔记` — 条件。使用 `[[标题]]：说明` 格式。
- 无内容的区段完全省略，不留空标题。

# Reference Note Templates

## 标准模板（完整内容）

适用于有观点、有思考的收录内容。

```markdown
# 内容标题
#reference/子标签

> **来源：** [URL]
> **收录：** YYYY-MM-DD

## 关键内容

（用自己的话总结核心观点。不收录全文——这是整理而非搬运。
必要时引用原文摘要，用 `>` 标记）

> 原文关键段落

## 我的思考

（仅在用户有评论性发言时写入。用 `> 💭` 前缀区分用户原话与润色。）

> 💭 用户原话

## 关联笔记

- [[相关笔记标题]]：关联说明
```

## 简洁模板（快速收录）

适用于纯记录、无评论的内容。

```markdown
# 内容标题
#reference/子标签

> **来源：** [URL]
> **收录：** YYYY-MM-DD

## 关键内容

核心要点总结。

## 关联笔记

- [[相关笔记]]
```

## 字段说明

| 字段 | 是否必需 | 说明 |
|------|---------|------|
| 标题 (line 1) | ✅ 必需 | 内容标题，不需要日期前缀。收录时间在元数据中 |
| 标签 (line 2) | ✅ 必需 | `#reference/<子标签>`，遵循标签体系 |
| 来源 | ✅ 必需 | URL / 文件名 / 「手动粘贴」/「个人想法」 |
| 收录日期 | ✅ 必需 | YYYY-MM-DD 格式 |
| `## 关键内容` | ✅ 必需 | 用自己的话总结。不收录全文 |
| `## 我的思考` | 条件性 | 用户有评论 → 写入；纯指令 → 省略；不追问 |
| `## 关联笔记` | 条件性 | 至少 1 条关联 → 保留；无关联 → 完全省略 |

## 区段规则

- **「## 关键内容」**: 必需。描述型总结，引用型补充。用 `>` 标记原文引用。不搬运全文。
- **「## 我的思考」**: 条件性写入。仅在用户表达了个人观点/评论时才创建此区段，不要因为「应该有」而追问用户。
- **「## 关联笔记」**: 条件性写入。仅在能找到至少一条有意义的关联时才保留，无关联就完全省略整个区段。

6. Classification

Decision→ Type
关于「你是谁、你喜欢什么、怎么工作」user
关于「你做错了、应该这样做」feedback
关于「这个项目正在发生什么、约束条件」project
关于「信息在哪里能找到」reference
不确定project（默认）

Agent 创建记忆后输出分类理由，用户可在 Bear 中直接修改标签纠正。

7. Retrieval & Ranking

score = 0.6 × similarity(query, memory) + 0.3 × recency(days) + 0.1 × confidence_boost
  • similarity — cosine on all-MiniLM-L6-v2 embeddings (384-dim)
  • recency — exponential decay, half-life 30 days
  • confidence_boost — 1.5× for confirmed, 0.8× for inferred

8. Storage & Sync

ArtifactLocationSync
Memory notes (content)Bear database, #ai/memory/*/entryiCloud automatic
Vector index~/.bear-memory-index/embeddings.jsonlPer-device, embed.py --rebuild

Vector index is NOT in git repo. iCloud syncs note content across devices; each device runs embed.py --rebuild once on first use to rebuild the index from its local Bear database.

Known Limitations

  • Initial model download (~80MB) requires network; fully offline after first run
  • Baseline scores (~0.49): improves with more diverse memories in the index
  • No explicit synonym expansion (relies on model training data)
  • read_note_content offset/limit bug (Bear MCP); full read fallback used
